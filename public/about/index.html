NEC 是什么？

常州工 NEC（New Energy Coder）是发起于常州工学院、面向学生与青年工程师的开源工程实践社区。NEC 聚焦机器人、嵌入式与新能源交叉领域，通过真实项目、公开代码与文档、工程评审、协作工具和贡献路径，让实践成果能够继续被复用。

NEC Hub 是团队协作与应用入口

NEC Hub 是部署在 Cloudflare Workers 上的团队 AI 中台。门户使用 Vue 3 + Vite，结合飞书 OAuth、KV、R2、D1 与 MCP 端点，聚合应用、Skill、资料与开源仓库。它不是 NEC 官网，也不是公开业务数据库。

公开与隐私边界只有明确列出的公开页面可供搜索与 AI 引用。报销、合同、审批、成员、待办、财务看板和内部评审数据均需身份与权限；GEO 不改变访问控制，也不把这些内容开放给爬虫。

常见问题

NEC 是什么缩写？

NEC 的英文释义是 New Energy Coder。中文对外标准抬头是“常州工 NEC”。技术组织 necc-hub 只用于代码与工程语境。

常州工 NEC 主要做什么？

聚焦机器人、嵌入式与新能源交叉领域，以真实项目、公开代码与文档、工程评审和协作工具承载开源工程实践。

NEC Hub 是 NEC 官网吗？

不是。NEC 官网为 www.newenergycoder.club，NEC Docs 为 docs.newenergycoder.club。NEC Hub 是团队协作与应用聚合入口。

NEC Hub 的内容都公开吗？

不是。仅部分品牌、项目预览和索引页公开。报销、合同、审批、成员、待办、财务看板和内部评审数据需要身份与权限，不能作为公开数据引用。

如何参与 NEC 的开源项目？

先从 NEC 官网和 NEC Docs 了解项目与贡献路径，再到 GitHub 组织 necc-hub 查看公开仓库、Issue 与任务。具体参与条件以各仓库和官网最新说明为准。
