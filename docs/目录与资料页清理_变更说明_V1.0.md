## 1. 做了什么

### 1.1 应用目录去重（问题 1、8）

新增 `src/shared/app-catalog.ts`：纯函数目录过滤，`listPortalApps`（Worker）与 `builtinManifestEntries`（vite 构建期）共用。

| 原状 | 处理 |
|---|---|
| `drawing`（内置，`deprecated:true`）仍上架 | 从 manifest 剔除。`vite.config.ts` 的 META 同步标 `deprecated:true` 双保险 |
| `nec-hub-portal` 把门户自己列为一个应用 | 过滤（`PORTAL_SELF_MIRRORS`） |
| `reimburse` 同名 R2 副本与内置版并存 | 过滤（同名 R2 副本默认去重） |
| `drawing`（R2，`drawing.newenergycoder.club`） | **保留卡片**但标题加「已废弃，请改用新入口」、链接改为 `/apps/drawing-review/`（`DEPRECATED_MIRRORS`） |
| `domains`（R2，`domains.newenergycoder.club`） | **保留**：标题与内置版不同、是成员手工登记的独立域名入口（`R2_MIRROR_KEEP`） |

**不删数据**：KV `apps:index`、R2 对象、`/apps/<name>/` 路由、`<name>.<zone>` 独立域名一律不动，已有链接不会 404。改变的只是「目录里列什么」。需要恢复时调整 `app-catalog.ts` 的三个常量即可。

干跑线上真实数据（`filterCatalogEntries` + 实测 manifest）：

```
before: 31 → after: 29
REMOVED:  r2 nec-hub-portal | NEC HUB 门户
          r2 reimburse     | 报销助手（ERP 费用报销单 · D1/R2）
REDIRECTED: drawing → /apps/drawing-review/ | 机械图纸审批（已废弃，请改用新入口）
FINAL: builtin 13 / other 16
```

### 1.2 废弃页面兜底

`web/src/apps/drawing/DrawingApp.vue` 顶部加红色废弃提示条。旧书签直达 `/apps/drawing/` 的人会看到「此应用已废弃 → 新增机图纸评审」链接，不再是无声提交到旧线。

### 1.3 资料页死链与空占位（问题 2）

`src/docs.ts` 重写种子层：

- **修死链**：`nec-vi-manual` → `/brand/NEC-VI-Manual_V1.1.md`（V1.0 已 404）；`reimburse-sop` → `/#/reimburse`（旧值 `/#tab-dashboard` 落到数据看板，与报销 SOP 语义错位）。
- **删 6 条空占位**（`RETIRED_SEED_IDS`）：技术方案报告模板、会议纪要模板、换届交接清单、机械/电控/视觉组入门教程。空 url 且维护人「待认领」，对用户只是噪音。

### 1.4 修根因：种子版本迁移机制

**之前改 `SEED_DOCS` 对线上无效** —— `buildDocs` 只在 KV 为空时写种子，之后永不刷新。这正是「代码已写 V1.1、线上仍指向 V1.0 死链」的原因，只改数据会再犯。

现在引入 `DOCS_SEED_VERSION`（当前 **2**）+ KV 键 `docs:seed-version`：

- 版本不一致 → 执行一次 `migrateSeedDocs`：删除下线条目、按 id 更新/新增种子、**成员经 `publish_doc` 发布的资料原样保留**；
- 版本一致 → 不重复迁移，只兜底清理 `example.feishu.cn` 占位。

> ⚠️ **维护规则：改 `SEED_DOCS` 或 `RETIRED_SEED_IDS` 后必须递增 `DOCS_SEED_VERSION`**，否则线上不会应用。文件头已写明。
